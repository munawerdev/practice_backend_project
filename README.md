# practice_backend_project

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init & bun init -y` in bun v1.4.2. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

# Development — with hot reloading

bun run dev

# or simply

bun dev

# Production — build then start

bun run build
bun run start
